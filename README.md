# Student Management System
- This is a Student Management System that stores records of students using a unique ID.
- Students details include Name, Age, Course and Marks.

## Features include : 

- **Display Student**
Displays the details of all students.
 
- **Search Student By ID**
Search for a student using a unique ID.

- **Add a new student** 
Add a student record with details such as Name, Age using unique ID.

- **Update student details**
Updates the record of a student using ID.

- **Delete student**
Deletes record of a student using their ID.
